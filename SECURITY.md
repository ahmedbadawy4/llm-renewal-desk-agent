# Security policy

This repository is a personal reference setup, not a production system. There is no release line to support: only the latest commit on the default branch is maintained.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Use GitHub private reporting instead:

1. Open the [Security tab](https://github.com/ahmedbadawy4/llm-renewal-desk-agent/security).
2. Choose **Report a vulnerability**.
3. Describe the problem and how to reproduce it.

Reports are read on a best-effort basis. If a report is valid, the fix goes to the default branch first and the advisory is published after that.

## Secrets

If you find a credential in this repository or in its history, report it the same way and do not use it.
